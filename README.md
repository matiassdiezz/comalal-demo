# Comalal · Demo del reporte de gestión

Demo para revisar la presentación de caja, cheques, cereales, leche e insumos. Todos los datos son ficticios.

**Vista simple (celular).** Una pregunta por tema con el número grande, la planilla y la fecha de donde sale, detalle en pantallas con «Volver» y letra Atkinson Hyperlegible de 20 px que se puede agrandar. «Enviar resumen» arma una imagen para WhatsApp, un texto listo para el grupo, un PDF de una página y el PDF completo.

**Vista completa (compu y reuniones).** Índice por tema, cifras con su fuente, gráficos de caja, cereales, leche e insumos con sus tablas, detalle de cada semana al pasar el mouse, modo presentación y PDF horizontal, una hoja por tema.

También incluye la vista de preparación y una actualización de insumos de ejemplo. No se conecta a bancos, Albor ni otros sistemas.

Sitio estático: `index.html` contiene todos sus assets, la tipografía y los datos de ejemplo.
