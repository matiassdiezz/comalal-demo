# Comalal · Demo del reporte de gestión

Demo para revisar la presentación de caja, cheques, cereales, leche e insumos. Todos los datos son ficticios.

Incluye las vistas de lectura y preparación, una actualización de insumos de ejemplo, exportación a PDF y comentarios descargables. No se conecta a bancos, Albor ni otros sistemas; los comentarios no se envían automáticamente.

Sitio estático: `index.html` contiene todos sus assets y datos de ejemplo.
