# Comalal · Demo del reporte de gestión

Demo para revisar la presentación de caja, cheques, cereales, leche e insumos. Todos los datos son ficticios.

La vista de lectura está pensada para leerse en el celular: una pregunta por tema con el número grande, la planilla y la fecha de donde sale, detalle en pantallas con «Volver» y letra Atkinson Hyperlegible de 20 px que se puede agrandar. «Enviar resumen» arma una imagen para WhatsApp, un texto listo para el grupo y un PDF de una página.

También incluye la vista de preparación, una actualización de insumos de ejemplo y el PDF completo. No se conecta a bancos, Albor ni otros sistemas.

Sitio estático: `index.html` contiene todos sus assets, la tipografía y los datos de ejemplo.
